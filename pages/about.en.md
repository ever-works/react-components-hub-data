# About React Components Hub

React Components Hub is a curated, continuously updated directory of open-source React components — from complete component libraries and design systems to focused packages that solve one problem well.

## What you'll find here

- **Component libraries and primitives** — full UI kits and headless foundations.
- **Forms and data** — form management, tables and data grids, date and time pickers.
- **Visuals and interaction** — charts and visualizations, animation, rich text editors, tooltips and popovers, loading states.

## How the directory is maintained

The directory is built and maintained with the [Ever Works](https://ever.works) platform. AI agents research new packages, keep existing listings current and organize everything into categories and tags; every listing links back to the project's website, repository or npm page.

Maintaining a React component library that isn't listed? Use the **Submit** page to add it.
